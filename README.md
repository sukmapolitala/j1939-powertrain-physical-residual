# Operating-state-conditioned physical residual monitoring of diesel powertrains

**Reproducibility repository for the scientific study**

*Operating-State-Conditioned Physical Residual Anomaly Detection from SAE J1939 for Heavy-Duty Diesel Powertrains*

This repository publishes the **author-created processing code, strict-causal experimental protocol, software tests, configurations, and aggregate result tables**. It does not claim to contain new vehicle field recordings. Network identifiers and source annotation are used internally for decoding/event segmentation where necessary, **never as detector features**.

## Source recordings (not redistributed)

The empirical recordings belong to their original provider: [SystemsCyber/J1939_Attack_Datasets](https://github.com/SystemsCyber/J1939_Attack_Datasets). This research uses their `normal.log` and `labeled_TSC1.csv` files as *source recordings* and makes an independently derived physical-state analysis.

**No explicit dataset-redistribution licence was verified at the time of this release.** Do not commit the original recordings, row-level re-encoded recordings, or row-level derived SPN time series here without written upstream permission or another identified legal basis. An openly visible source repository is not, by itself, permission to republish its datasets.

For the record-level data and terminology provenance, see [`data/README.md`](data/README.md) and [`docs/DATA_RIGHTS.md`](docs/DATA_RIGHTS.md).

## Experimental design — strict causal

- Signal features: pedal, driver-demand torque, vehicle speed → expected engine-demand torque, actual torque, load, speed, fuel rate, intake pressure.
- Operating state is conditioned **continuously** with a degree-2 robust Huber regression; it is not a discrete K-means classifier.
- Proposed method: Huber response prediction → physical residuals → median/MAD → shrinkage covariance → normalized Mahalanobis → EWMA + persistence.
- Baselines: Isolation Forest and One-Class SVM trained on the same healthy data and separately calibrated on the same healthy calibration data.
- Fit and calibration: **independent normal run and strictly pre-event segment only**, each time-split 60% fit, 20% calibration, 20% held-out healthy test. All event rows are held out. Post-event rows are excluded from model fitting and primary test.
- Primary grid: 20 ms. Sensitivity: 50 and 100 ms. The source event is annotated externally; the event label is NOT a feature.

## Reproduction (Windows PowerShell or Linux/macOS terminal)

Requires Python 3.10+ (3.11–3.12 recommended). Install packages:

```bash
python -m venv .venv
# Windows: .venv\Scripts\Activate.ps1
# Linux/macOS: source .venv/bin/activate
python -m pip install -r requirements.txt
```

Download upstream source files **for local use** (do not commit):

```
data/local_raw/normal.log
data/local_raw/labeled_TSC1.csv
```

Validate original file identities using [`data/SOURCE_SHA256.txt`](data/SOURCE_SHA256.txt). Construct local-only derived physical telemetry at three resolutions:

```bash
python scripts/decode_physical_j1939.py --raw-dir data/local_raw --out-dir data/local_derived/20ms --period-ms 20
python scripts/decode_physical_j1939.py --raw-dir data/local_raw --out-dir data/local_derived/50ms --period-ms 50
python scripts/decode_physical_j1939.py --raw-dir data/local_raw --out-dir data/local_derived/100ms --period-ms 100
```

Then run the strict protocol:

```bash
python scripts/run_primary_strict.py
python scripts/run_sensitivity_strict.py
python scripts/run_bootstrap_1000.py
python -m unittest discover -s tests -v
```

Outputs: aggregate method performance, ablation, bootstrap uncertainty, sensitivity, and robustness under `results/`; **per-sample outputs and fitted model files are ignored by Git** to avoid inadvertent redistribution of derived source data. Run `python scripts/make_figures.py` to regenerate publication benchmark and ROC/PR figures locally.

> Reproducibility caveat: this code allows authorized users to reproduce the computations; absent upstream permission, the public repository does not provide independent access to row-level recordings.

Read `docs/RESULTS_INTERPRETATION.md` for the failure modes that must be reported with the benchmark.

## Public data policy

Published repository contents may include *newly computed summary metrics* and diagnostics generated by the authors. Raw recordings and **row-level derivatives** (time-indexed SPN values, raw event labels, row-level predictions and fitted models) are excluded pending redistribution clearance. The public results are scientific aggregate statistics, not an alternative source of the provider's telemetry.

## Citation and release

Please cite the original source provider as well as the associated article. On submission, create a frozen git tag; when the paper metadata is final, update `CITATION.cff` and optionally archive a reviewed release via Zenodo.

## Limitations

This is **physical-state abnormality detection**, not mechanical-component fault diagnosis and not general evidence over independent vehicles or failures. The controlled abnormal event comprises one temporally contiguous interval. No Jetson hardware benchmark is claimed here.
